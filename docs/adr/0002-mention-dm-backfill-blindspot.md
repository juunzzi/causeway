# ADR-0002: 멘션/DM의 백필 사각지대를 수용한다

- 상태: 채택 (2026-07-13)

## 맥락

Slack Socket Mode는 봇이 좀비/다운 상태였던 동안의 이벤트를 소급 재전송하지 않는다(실측).
워처 채널은 채널이 특정돼 있어 커서 백필로 전량 복구가 가능하지만, @멘션/DM은 "모든 채널"이
대상이라 커서 백필이 비현실적이다.

## 결정

- 좀비 probe가 `conversations.history`(top-level) + `conversations.replies`(최근 관여 스레드)로
  최근 유실분을 재주입한다 — dedup_key가 replay 안전을 보장.
- **오래된 스레드의 답글 멘션은 probe 휴리스틱 밖 사각지대로 수용한다.**
- 복구/재시작 안내 메시지에 "복구 전 발송된 멘션은 유실될 수 있으니 다시 멘션해 달라"
  문구를 유지한다.

## 대안 검토

전 채널 열거 백필은 rate limit·비용상 기각. Events API(웹훅) 전환은 재전송 보장이 있으나
공개 엔드포인트 인프라가 필요해 현 단계에서 기각 — 상시 서버 이전 시 재검토 후보.
