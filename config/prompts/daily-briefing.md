# 예시 스케줄 프롬프트

`config/schedules.json` 의 `promptFile` 이 가리키는 파일이다. 발화 시각이 되면 이 내용이 그대로
세션 프롬프트가 되고, 결과는 지정한 슬랙 채널의 스레드에 달린다.

여기에 실제로 시킬 일을 쓴다. 예:

- 오늘 날짜를 확인하고(`date +%Y-%m-%d`), 최근 24시간 내 관심 주제를 조사해 한국어로 요약하라.
- 결과를 `<레포>/briefings/YYYY-MM-DD.md` 로 저장하고 커밋·푸시하라.
- 마지막 메시지에 요약 전문을 출력하라(그게 슬랙에 게시된다).

**세션은 매번 새로 시작한다** — 이전 실행을 기억하지 못하므로 프롬프트는 자기완결적이어야 한다.
